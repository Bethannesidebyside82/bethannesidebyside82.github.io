Christine Nowak – Website mit kuratierter Bildauswahl

Öffne index.html direkt im Browser. Die beiden persönlichen Fotos und das Hintergrundbild sind zusätzlich direkt in index.html und en.html eingebettet und funktionieren auch ohne assets-Ordner. Für GitHub Pages dennoch den gesamten Ordnerinhalt hochladen.

Bildauswahl: Porträt (weiße Bluse), Präsentation (rotes Oberteil), Meeresterrasse als atmosphärisches Hintergrundbild.

Vor Veröffentlichung Impressum/Datenschutz prüfen. Nach Veröffentlichung kanonische URLs, hreflang und Open-Graph-Bild auf absolute HTTPS-Adressen umstellen.
